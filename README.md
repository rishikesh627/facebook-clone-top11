A **Facebook login UI clone** built with **HTML, Tailwind CSS, and Vite**. Front-end practice project and a base for future JS/React features. No real authentication.

> Not affiliated with Meta / Facebook.

## Features

- Facebook-style login / signup layout
- Styled with Tailwind CSS utility classes
- Vite for fast local development and builds

## Getting started

```bash
git clone https://github.com/Danyal-0276/facebook-clone.git
cd facebook-clone
npm install
npm start
```

Then open the URL Vite prints (usually `http://localhost:5173`).

```bash
npm run build   # production build
```
