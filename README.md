# facebook-clone

Facebook login UI clone with Tailwind/Vite. Base for future JS/React features.

## Run locally

Open `index.html` in a browser, or use [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer).

> Projects that use `fetch` or a Vite/Tailwind build work best over `http://localhost`.

## Tech

HTML, CSS, and JavaScript (vanilla unless noted in the project files).
